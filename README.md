# Future Schools Excellence Summit

Premium multilingual conference website built with React + Vite + TypeScript + Tailwind CSS + Framer Motion.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

- /
- /about
- /program
- /speakers
- /workshops
- /audience
- /partners
- /register
- /contact

## Languages

- English
- Français
- العربية (RTL)

## Visual identity

Navy `#071A2B`, Deep Blue `#0B3155`, Royal Blue `#0B5CAD`, Sky `#4DA3D9`, Champagne `#C9A96E`, White / Mist.
